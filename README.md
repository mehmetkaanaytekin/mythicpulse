All-in-one Mythic+ companion for WoW: Midnight. Spec-aware cooldowns with aura highlights, kick rotation, dispels, trinkets, auto-gossip, score prediction, demo mode, and more.


## Features
- **Spec-aware party cooldown tracker** (defensives, externals, raid CDs, utility) with aura highlights and dispel indicators
- **Interrupt tracker** with rotation support, click-to-announce, and cross-party sync
- **Dispel tracker** for all group members
- **Dynamic trinket tracker** (no static database needed)
- **Custom dungeon timer bar** with +2/+3 thresholds, live pace, and personal bests
- **Enemy forces tracker** with pull count and progress bar
- **Affix display** with icons, tooltips, and key-level activation
- **Keystone tracker** for your and party members’ keys
- **Dungeon utility recommendations** based on your class/spec/race
- **Auto-gossip and auto-slot** for keystone NPCs
- **Death tracker** with penalty display
- **Dungeon teleport integration** (teleport buttons in Challenges UI)
- **Run history and score prediction**
- **Demo mode** for testing features outside dungeons
- **Highly customizable UI** and Blizzard-compliant (no automation)

## Slash Commands

You can use the following slash commands in-game (all work with `/mp` or `/mythicpulse`):

- `/mp` or `/mp help` — Show a list of available commands
- `/mp toggle` — Toggle the main display
- `/mp config` — Open the configuration/settings panel
- `/mp lock` — Lock or unlock all frames
- `/mp reset` — Reset all frame positions to default
- `/mp keys` — Announce all party keystones in chat
- `/mp history` — Show your run history
- `/mp summary` or `/mp last` — Show your last run summary
- `/mp utility` or `/mp util` — Toggle the dungeon utility panel
- `/mp rotation`, `/mp rot`, or `/mp kicks` — Announce the kick rotation
- `/mp demo` — Toggle demo mode (test layout outside dungeons)
